# Dashboard Executivo de Vendas — Excel

## Sobre o projeto

Projeto de análise e visualização de dados desenvolvido no Microsoft Excel, com o objetivo de transformar uma base de vendas desorganizada em informações claras para acompanhamento de resultados e indicadores.

## Tratamento e preparação dos dados

Antes da criação do dashboard, os dados foram tratados e padronizados para garantir maior qualidade e consistência das informações.

Foram utilizadas funções e recursos do Excel, incluindo:

* `TRIM` — remoção de espaços desnecessários;
* `CLEAN` — remoção de caracteres não imprimíveis;
* `SUBSTITUTE` — substituição de caracteres indesejados;
* `CHAR(32)` — tratamento de espaços;
* `CHAR(160)` — tratamento de espaços não separáveis;
* Padronização e organização das informações;
* Estruturação da base para análise.

## Dashboard

Após o tratamento dos dados, foram criados indicadores, tabelas e gráficos para facilitar a análise das vendas.

O dashboard permite acompanhar informações como:

* Faturamento total;
* Quantidade de transações;
* Desempenho dos vendedores;
* Desempenho dos produtos;
* Análise por categorias;
* Indicadores de vendas.

O **background visual do dashboard foi desenvolvido no Microsoft PowerPoint**, buscando organizar os elementos e melhorar a apresentação visual das informações.
